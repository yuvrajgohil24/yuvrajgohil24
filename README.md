## 🚀 Featured Projects

### 🤖 [AI Calling Agent](https://github.com/yuvrajgohil24/ai-calling-agent)
> *Automated telephony system for user onboarding*

Triggers a personalized AI voice call within 30 minutes of user signup. **BullMQ + Redis** schedule the jobs, **Twilio Media Streams** carry two-way audio, **Whisper** handles speech-to-text, **GPT-4o-mini** drives the conversation, and **ElevenLabs** generates the voice, with a Twilio fallback for API outages.

`TypeScript` `Node.js` `BullMQ` `Redis` `Twilio` `OpenAI` `ElevenLabs` `Docker`

---

### 🔍 [DevLens](https://github.com/yuvrajgohil24/DevLens) · [Live](https://dev-lens-frontend-sable.vercel.app/)
> *Unified DevSecOps dashboard for pipelines, security scans, and deployment health*

Aggregates CI/CD events, automated security scans (SCA/SAST), and deployment status into one real-time view. A webhook-driven pipeline (**GitHub push → BullMQ → Trivy & TruffleHog → PostgreSQL → Socket.io**) runs in a Dockerized Next.js + Express monorepo with Slack alerts, CI, and unit tests.

`Next.js 15` `Express 5` `TypeScript` `PostgreSQL` `Redis` `BullMQ` `Socket.io` `Docker` `Trivy` `TruffleHog`

---

### 🌉 [ContextBridge](https://github.com/yuvrajgohil24/Context-Bridge) · [Live](https://context-bridge-smoky.vercel.app/)
> *Chrome extension + Next.js app for moving AI context across platforms*

Captures conversations from Claude and ChatGPT in one click, keeping message roles intact, then uses **Gemini** with custom prompt engineering to compress long chats into structured snippets that preserve hard facts. Shipped with Vitest and GitHub Actions CI.

`Chrome Extension MV3` `Next.js` `React 19` `TypeScript` `Google Gemini SDK` `Vitest`
